# ScreenshotMaker

ScreenshotMaker is a small Windows desktop utility for creating screenshots with hotkey support.

## Overview

The project is built as a classic Windows Forms application on .NET Framework 4.7.2. It uses screen capture and keyboard hook libraries to provide a lightweight screenshot workflow for Windows.

## Tech Stack

- C#
- Windows Forms
- .NET Framework 4.7.2
- Screna
- MouseKeyHook / hotkey libraries

## Running Locally

Open `ScreenshotMaker.sln` in Visual Studio and build the solution.

You can also build from the command line with MSBuild if the .NET Framework build tools are installed.
